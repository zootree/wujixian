# 無極限｜南港高工土建群技能競賽選手隊

南港高工土建群技能競賽選手隊（砌磚、漆作裝潢、建築鋪面）介紹網站。目前尚未公開發布。

## 結構
- `index.html`：首頁（含 CSS/JS）
- `images/`：首頁使用的照片；`images/logo/`：文字 Logo（SVG）

## 如何編輯
1. `git clone` 此 repo，用 VS Code 等編輯器開啟 `index.html`。
2. 換照片：把新圖放進 `images/`（建議 < 1MB），修改 `index.html` 中對應的 `src`。
3. `git add . && git commit -m "說明" && git push`。

## 隱私原則
僅呈現姓名、年級、比賽、年度、名次與選手照片；不放任何個人資料（身分證、電話、地址、生日、獎懲等）。
